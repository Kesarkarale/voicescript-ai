# VoiceScript AI

VoiceScript AI is a modern AI-powered speech-to-text web application built with Next.js, TypeScript, Tailwind CSS, and Clerk Authentication.

## Features

* User Authentication (Login & Register)
* Modern Landing Page
* Professional Dashboard
* Audio & Video Upload Interface
* Transcript Preview
* AI Summary Section
* Upload History
* Settings Page
* Responsive Design
* Dark Theme UI

## Tech Stack

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* Clerk Authentication
* Vercel Deployment

## Pages

### Home Page

Landing page showcasing the product and its features.

### Dashboard

Central workspace for managing transcripts and uploads.

### Uploads

Displays uploaded audio/video files.

### History

Shows transcript history and activity.

### Settings

User settings and account management.

## Installation

```bash
git clone <repository-url>
cd voicescript-ai
npm install
npm run dev
```

## Deployment

The project is deployed using Vercel.
